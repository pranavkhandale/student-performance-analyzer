# Student Performance Analyzer

A Python application using NumPy to analyze student marks and generate class statistics.

## Features
- Calculate total marks for each student
- Calculate average marks for each student
- Find class topper
- Find highest marks in each subject
- Identify passed students (40+ in all subjects)
- Find students with above 75 average
- Grade classification (A, B, C, Fail)
- Subject-wise average calculation
- Find top performers in specific subjects
- Count total passed students

- ## How to Run
1. Install NumPy:
pip install numpy

2. Clone this repo:
git clone https://github.com/pranavkhandale/student-marks-analyzer.git

3. Run the file:
python student_marks_analyzer.py
